- 정답 배치를 읽지 않은 화면 관찰에서는 02번의 수험표와 12번의 안경 반사를 보고 신고를 보류하고, 03번의 이어폰·충전 케이스를 확인해 적발했다. 브라우저 시계를 나눠 진행한 부분 플레이이며 한 판 완주나 외부 플레이테스트는 아니다.
- 에셋 회귀 플레이는 실제 예약된 행동이 나올 때까지 터치로 접근·관찰하여 새 소품 네 상태와 일상 행동 네 종류를 캡처했다. 소품 검토용 고정 배치이므로 추리 성공률 측정과는 구분한다.
- 시계는 양팔과 연필 자세가 동일하고 문자판만 다르다. 일반 시계의 원형 눈금과 답 목록을 390px·320px에서 구별했다. 펜의 표시부는 손 밑에 노출되고 일반 펜의 뚜껑과 몸통도 확인했다.
- 소매·손목 동작에서는 연필을 내려놓고 양손을 사용한다. 목 스트레칭에서는 뒤쪽 목에 손을 가져가 고개를 움직이며, 다시 읽기는 손을 지문 위로 옮긴다. 필기로 돌아갈 때 소품이 남거나 관절 변환이 깨지지 않는지 검사했다.
- 국내 2026-11-17 공식 발표와 Ofqual 2026-06 자료로 소재의 현재성을 확인했다. 출처와 실제 규정/게임 각색의 차이는 [기획 문서](../product/art-direction.md)에 기록했다.

### 검증 범위

- 단위 테스트 19개 통과. 1,000개 배치의 단서 노출·이동 계획, 정상/부정행위 동일 문구, 새 행동의 양쪽 배정, 소품 초기화·자세 일치 포함.
- 1,000개 배치의 최단 관찰 계획은 1단계 평균 20.7초, 5단계 평균 31.1초였다. 정답·시점을 아는 조건이며 요청을 생명으로 감수한다. 일반 플레이어의 클리어 시간이나 성공률이 아니다.
- Chrome 터치 브라우저에서 오인 패배, 시간 종료, 생존 승리, 일시정지·무음·팡파르, 답안지·커튼, 재시작, 5개 화면 크기를 통과했다. 다섯 단계 승리·해제·저장·재도전도 통과했다.
- 프로덕션 빌드 통과. 기존 Three.js 청크의 500kB 경고는 남아 있다. 실기기 성능과 외부 플레이어의 재미 평가는 별도 확인이 필요하다.

## 링크 미리보기 검증

`6c613d0`에서 정적 HTML에 Open Graph와 X 큰 이미지 카드 메타데이터를 추가했다. 빌드 후 공개 페이지에 카카오 스크랩 크롤러 User-Agent로 접근해 제목·소개·이미지 절대 URL을 읽고, 대표 JPEG의 HTTP 200과 MIME 유형을 확인했다. Vercel 프로덕션 배포의 READY 상태와 커밋도 확인했다.

카카오톡 대화방에 직접 메시지를 보내거나 실제 카드 UI를 검증한 것은 아니다. 캐시 갱신과 운영 확인법은 [공유·배포 문서](../engineering/sharing-and-deployment.md)에 기록한다.

## 새 검증을 기록하는 방식

날짜, 코드 커밋, 브라우저/화면 크기, 배치가 고정인지 무작위인지, 시계 제어 여부, 수행한 입력, 관찰 결과, 남은 한계를 함께 적는다. 자동으로 정답을 아는 테스트를 신규 플레이어의 추리 성공으로 표현하지 않는다. 과거 통과 기록은 새 변경의 통과를 보장하지 않는다.
