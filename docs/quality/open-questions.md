## 현재 결정을 유지할 항목

자동 테스트가 쉽다는 이유로 일반 플레이도 쉽다고 결론 내리지 않는다. 반대로 물리적으로 가능한 판이라는 이유만으로 인간에게 공정하다고 결론 내리지 않는다. 정답·시간을 아는 최적 경로 검사는 하한 확인이다.

실시간 적발 수, 단계 힌트, 깜빡임, 떠 있는 요청 카드, 90초로의 복귀는 확정한 후속 작업이 아니다. 다시 제안할 때는 기존 제거 이유와 사용자의 새 요구를 함께 검토한다.
