# 냥이잡기 문서 홈

정리일: 2026-11-18 · 최신 변경: 모달 재정리·공유 주소 결합 수정 · 공개 주소: https://cat-hunting.vercel.app/

이 문서들은 대화에서 결정한 방향, 현재 구현, 검증 증거, 미확인 사항을 다음 작업으로 이어가기 위한 기록이다. 대화 원문 전체를 옮긴 속기록이 아니라, 확인 가능한 대화와 저장소 이력을 근거로 정리한 요약이다.

에이전트는 작업 전에 루트의 [AGENTS.md](../AGENTS.md)를 먼저 읽는다. 필수 문서 순서, 현재 결정을 유지하는 규칙, 변경별 검증, 협업·커밋·인계 방법을 정리했다.

## 처음 읽는 순서

1. 아래 ‘빠른 인계’로 현재 방향을 파악한다.
2. [현재 게임 기획](product/game-design.md)에서 플레이 규칙을 읽는다.
3. [대화와 결정 이력](decisions/conversation-log.md)에서 변경 이유와 취소된 결정을 확인한다.
4. 작업에 맞는 [개발 안내](engineering/development.md), [현재 검증](quality/current-review.md), [미검증 항목](quality/open-questions.md)을 읽는다.

## 빠른 인계

- 결과는 캐릭터 반응·대사를 1.8초 보여준 뒤 중앙 모달을 연다. 제목·성적표·행동을 묶고 실패의 ‘부정행위 다시 보기’를 가장 강조한다.
- 하루 재도전 기본 3회, 실패 때 1회 차감. 0회 도전 버튼은 공유 안내를 연다. 공유 성공/복사 성공 뒤 화면에 돌아와 내부 5초 대기하면 3회 추가하며 대기 시간은 UI에 표시하지 않는다. 일일 보상 횟수 제한은 없다. 한국 자정에 3회로 초기화한다.
- 공유는 URL 하나만 전달하고 현재 단계는 링크 미리보기에 표시한다. 10개 결과별 정적 주소와 단계 이미지, 5단계 전체 통과 축하 이미지를 제공한다. 받은 사람의 진행은 바뀌지 않는다.
- 모바일 3D 시험 감독 게임. 점토 교실의 **12명**을 **단계당 45초, 총 5단계** 동안 관찰한다.
- 최신 피드백은 첫 판이 너무 어렵다는 것이다. 기존 1단계를 난이도 2의 기준으로 옮기고 새 1단계는 더 쉽게, 이후는 1점씩 높아지는 것을 목표로 재조정했다. 초심자 성공률과 체감 간격은 아직 측정하지 않았다.
- 부정행위와 일반 행동을 비슷하게 만든다. 문장이 정답을 알려주지 않고, 화면에서 소품을 살펴 판단한다.
- 큰 번호표·떠 있는 민원 카드·실시간 적발 합계·단계별 공략 힌트·눈 깜빡임 암전은 사용하지 않는다.
- 실패 결과의 ‘부정행위 다시 보기’에서 해당 판의 실제 3D 행동을 반복 관찰한다. 놓친 학생부터 이전·다음으로 전환하며 이미 적발한 학생도 포함한다. 게임 도중에는 정답을 공개하지 않는다.
- 감독관은 교탁 뒤에서 뒷모습으로 대기한다. 가구를 피해서 걸어가며 도착 후 상호작용하고, 신고·도움·관찰 종료 후 복귀한다. 복귀 중에도 학생을 누르면 현재 위치에서 바로 그 학생에게 향한다.
- 오인당한 학생의 억울함과 남는 울상, 커튼을 실제로 닫는 과정처럼 행동의 결과를 보여준다.
- 새 시계·펜과 네 가지 일상 행동은 별도 에이전트가 만들고 통합 담당자가 검토·수정했다. 시의성 근거와 게임적 각색은 별도 기록했다.
- 사용자는 이 작업의 변경을 `main`에 반영하고 커밋·푸시하도록 명시했다. GitHub의 `main` 푸시가 Vercel 프로덕션 자동 배포로 이어진다.
- 카카오톡 링크 미리보기용 제목·소개·대표 이미지가 공개 HTML에 포함되어 있다. 실제 카카오톡 카드 UI는 아직 직접 검증하지 않았다.

## 문서를 갱신하는 규칙

실제 동작을 확인할 때는 코드, 사용자 의도를 확인할 때는 최신 명시적 요청, 검증 여부는 날짜와 커밋이 있는 기록을 기준으로 삼는다. 문서와 코드가 다르면 차이를 기록하고 현재 사양을 고친다. 과거 문서의 내용만으로 취소된 기능을 되살리지 않는다.

| 변경 종류 | 함께 갱신할 문서 |
| --- | --- |
| 플레이 규칙·시간·난이도 | 게임 기획, 결정 이력, 관련 검증 |
| 소품·캐릭터·동작 | 아트 방향, 관련 캡처와 검증 |
| 도메인·배포·공유 메타데이터 | 공유와 배포, README의 공개 링크 |
| 플레이테스트·새 결함 | 현재 검증 또는 미검증 항목 |
| 기존 결정 취소 | 결정 이력에 새 행 추가, 현재 사양 수정. 이전 결정의 맥락은 보존 |

수치 표는 게임 기획에서, 실행 명령은 개발 안내에서, 공개 주소와 미리보기 운영은 공유·배포 문서에서 상세 관리한다. 보관 문서의 옛 점수와 스크린샷은 당시 기록으로 남긴다. 임시 로컬 경로나 인증 정보는 인계 자료로 사용하지 않는다.
