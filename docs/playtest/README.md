45초 에셋 화면은 고정 배치와 제어된 브라우저 시계로 실제 게임의 행동이 나타날 때 캡처했다. 자유 플레이의 성공률이나 물리 휴대폰 성능 증거가 아니다. 새 캡처를 추가하면 해당 검증 문서에 날짜·커밋·조건·관찰을 적고 이 표에 연결한다.
